# Recipe repository (template)

The machine and the phone download recipes over plain HTTP from a folder like this one. **Copy this folder into a
repository of your own** (private if it will hold recipes you didn't write), add your recipes, and serve it. The
full walk-through, including the optional upload service that lets the phone add recipes, is in
[../docs/SERVER-SETUP.md](../docs/SERVER-SETUP.md).

```
index.json                  list of recipes (generated by tools/build_index.py, don't edit)
recipes/<key>-<lang>.json   one file per recipe and language, format mcc-recipe/1 (FORMAT.md)
images/                     photos, referenced by relative path
converters/                 turn other recipe sources into mcc-recipe/1
tools/                      build_index.py, fetch_images.py
tests/                      python3 -m unittest discover -s tests
Dockerfile                  validates everything, then serves the folder with nginx
docker-compose.yml          runs that image on port 8088
```

The sample recipes in `recipes/` (`sample-*`) were written for this project and are MIT-licensed like the rest.
Delete them in your own copy if you like.

## Two languages per recipe

Every recipe exists in Portuguese (`pt`) and English (`en`), as `<key>-pt.json` and `<key>-en.json`, with the same
steps, grams and machine settings; only the text differs. The app shows the one that matches its language.
`tools/build_index.py` (and with it the Docker build) **fails when a translation is missing**.

## Adding a recipe

1. **From the phone app** (easiest): share a recipe page or a YouTube video to the app, review what the AI made,
   send corrections if needed, and tap Publish. Needs an AI server and the upload service
   ([../server/](../server)); the service writes both languages here, commits and redeploys.
2. **By hand**: copy a pair of `sample-*` files, give them a new key (`my-soup-pt.json` with id `my-soup-pt`, and the
   same for `en`), and follow [FORMAT.md](FORMAT.md). Steps are `instruction`, `weigh` (with a target in grams) or
   `machine` (time, speed, temperature and reverse per segment, or a `knead`, `roast` or `steam` preset).
3. **Converted from a website** that embeds schema.org Recipe data (most do):

   ```sh
   python3 converters/web_jsonld.py https://example.org/some-recipe recipes/ --id my-soup-pt --lang pt
   ```

   It recognises machine settings written like "20 sec/speed 5", "25 min/100 °C/speed 1", "turbo 2 sec",
   "roast button/3 minutes" or "Varoma" (→ steam). **Read the notes it prints and check every detected step
   before cooking.** Then add the English file yourself.

Then:

```sh
python3 tools/fetch_images.py     # optional: downloads remote photos into images/ as 640x400 JPEGs (needs Pillow)
python3 tools/build_index.py      # validates everything and rewrites index.json
python3 -m unittest discover -s tests
```

### Recipes from your own machine

`converters/mc2_bundled.py` converts the recipe JSON that ships inside the stock app on **your** machine
(`res/raw*/recipes.json` in the APK) for use on that machine. Those recipes and photos are copyrighted by their
publisher, so **keep the converted files in a private repository**. Never commit them to a public one.

## Serving

```sh
docker compose up -d --build         # on any Docker host: http://<host>:8088/
python3 -m http.server 8088          # or a quick test from a laptop, after build_index.py
```

The Docker build validates every recipe and regenerates `index.json`, so a broken recipe fails the build instead of
reaching the machine. After adding recipes: `git pull && docker compose up -d --build`.

The app only does `GET <base>/index.json`, `GET <base>/recipes/<file>` and image requests, so any static web server
works. It caches everything and keeps working offline.

## What the machine enforces anyway

Whatever a recipe says, the app refuses speed > 3 with heat or in reverse, more than 130 °C, more than 99 min
(15 min above speed 6), and heat with less than 200 g in the bowl. Turbo runs only while held (10 s at most, never
with heat or above 60 °C); knead, roast and steam use the stock presets with the same limits.
